# Оно тебе надо — лендинг аукциона

Этот проект демонстрирует промо-страницу вымышленного аукциона необычных вещей с акцентом на
типографику и выразительные визуальные эффекты.

## Ключевые особенности

- Верхний экран с затемнённым фоном, крупными заголовками и понятной кнопкой действия, которая сразу
  привлекает внимание.
- Каталог лотов с карточками, показывающими основную информацию о каждом предмете и ведущими к
  подробностям.
- Навигация с логотипом и контактами оформлена в едином стиле, что помогает быстро найти нужные
  разделы.
- Блок «Об аукционе» объясняет ценность проекта и удерживает внимание за счёт выверенного текста.
- Целостный визуальный стиль: фирменные шрифты, согласованные отступы и единая сетка.

## Использованные технологии

- **Интерфейс:** HTML5, CSS3, сетки CSS Grid и Flexbox, методология БЭМ
- **Контроль качества:** NPM Scripts, Prettier, Stylelint
- **Работа с ресурсами:** веб-шрифты Raleway (форматы WOFF/WOFF2), оптимизированные изображения JPG,
  иконки SVG

## Как запустить проект

- **Шаг 1.** Убедитесь, что установлены **Node.js 22+** и менеджер пакетов **npm**.
- **Шаг 2.** Установите зависимости:

  ```bash
  npm install
  ```

- **Шаг 3.** Запустите локальный сервер:

  ```bash
  npm run serve
  ```

- **Шаг 4.** Перейдите по адресу, который покажет `serve` (по умолчанию `http://localhost:3000`) и
  откройте лендинг в браузере.
- **Альтернатива.** Для статического просмотра достаточно открыть файл `index.html` напрямую в
  браузере.

## Что реализовано и изучено

- Семантическая структура HTML5 с акцентом на доступность без использования JavaScript.
- Сочетание сеток CSS Grid и Flexbox для многослойного макета фиксированной ширины 1100 px.
- Настройка и применение методологии **БЭМ** для поддерживаемой CSS-архитектуры.
- Подключение и оптимизация фирменных веб-шрифтов с резервными вариантами и корректной загрузкой.
- Настройка проверки и форматирования кода (Stylelint + Prettier) для единого стандарта качества.

## Решённые задачи

- Обеспечена читаемость текста на сложных фоновых изображениях за счёт управляемого затемнения и
  продуманной системы отступов.
- Собрана комбинированная сетка: CSS Grid для общего расположения блоков и Flexbox внутри карточек
  для предсказуемого поведения контента.
- Проработаны состояния ссылок и элементов навигации, чтобы избежать артефактов при взаимодействии и
  сохранить целостность дизайна.
- Стандартизированы единицы измерения, шрифты и стили ссылок, что упростило поддержку и расширение
  лендинга.
